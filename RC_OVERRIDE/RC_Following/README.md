# Система преследования дронов

## Описание

Система для управления двумя дронами, где один дрон (лидер) летает вперёд-назад, а второй дрон (последователь) его преследует.

## Структура файлов

- `CoordsMonitor.py` - класс для мониторинга координат дрона
- `VelocityMonitor.py` - класс для мониторинга скорости дрона
- `drone_following.py` - основной скрипт для преследования

## Использование

### Настройка

1. Убедитесь, что у вас запущены два дрона в симуляторе:
   - Дрон 1 на UDP порту 14550 (лидер)
   - Дрон 2 на UDP порту 14551 (последователь)

2. Настройте конфигурацию в `drone_following.py`:
```python
DRONES_CONFIG = [
    {
        'id': 1,
        'udp_port': 14551,
        'role': 'leader'
    },
    {
        'id': 2,
        'udp_port': 14561,
        'role': 'follower'
    }
]
```

### Запуск

```bash
cd RC_OVERRIDE/RC_Following
python drone_following.py
```

## Как это работает

1. **Инициализация**: Оба дрона подключаются, взлетают на высоту 1 метр
2. **Обмен координатами**: В отдельном потоке дроны обмениваются своими координатами
3. **Паттерн лидера**: Лидер летает вперёд-назад с интервалом 5 секунд
4. **Преследование**: Последователь использует П-регулирование для движения к лидеру

## Параметры настройки

В функции `follower_loop()` можно настроить:
- `kp` - пропорциональный коэффициент (по умолчанию 500.0)
- `max_intensity` - максимальная интенсивность управления (по умолчанию 200)

В функции `leader_pattern()` можно настроить:
- `duration` - длительность движения в одном направлении (по умолчанию 5 секунд)

## Классы

### CoordsMonitor
- `get_position()` - получить текущие координаты
- `get_distance_to(target_position)` - расстояние до целевой позиции
- `get_relative_position(target_position)` - относительная позиция

### VelocityMonitor
- `get_velocity()` - получить текущую скорость
- `get_horizontal_speed(direction)` - скорость в заданном направлении

### DroneController
- `move_towards(target_position, kp, max_intensity)` - движение к целевой позиции
- `update_other_drone_position(drone_id, position)` - обновить позицию другого дрона
- `get_distance_to_drone(target_drone_id)` - расстояние до другого дрона
