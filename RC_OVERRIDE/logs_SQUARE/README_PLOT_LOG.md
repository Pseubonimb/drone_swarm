# Построение графиков из лог-файлов координат

Скрипт `plot_log_coords.py` предназначен для построения графиков траекторий дронов из текстовых лог-файлов с координатами. Поддерживает отрисовку траекторий одного или нескольких дронов на одном графике.

## Формат файла

Скрипт ожидает файл, где каждая строка содержит словарь Python с координатами:
```
{'x': 2.126, 'y': -0.136, 'z': -1.100}
{'x': 2.126, 'y': -0.136, 'z': -1.100}
...
```

## Использование

### Один дрон

#### Базовое использование
```bash
python plot_log_coords.py logs/drone_following_log.txt
```

#### С кастомным заголовком
```bash
python plot_log_coords.py logs/drone_following_log.txt --title "Drone Following Pattern"
```

#### Сохранение графика в файл
```bash
python plot_log_coords.py logs/drone_following_log.txt --save trajectory.png
```

### Несколько дронов (2 и более)

#### Базовое использование (автоматические метки)
```bash
python plot_log_coords.py logs/drone_1_log.txt logs/drone_2_log.txt
```

#### С кастомными метками и заголовком
```bash
python plot_log_coords.py logs/drone_1_log.txt logs/drone_2_log.txt \
    --title "Leader and Follower" --labels "Leader" "Follower"
```

#### Сохранение графика нескольких дронов
```bash
python plot_log_coords.py logs/drone_1_log.txt logs/drone_2_log.txt \
    --save two_drones_trajectory.png
```

### Все опции
```bash
python plot_log_coords.py logs/drone_1_log.txt logs/drone_2_log.txt \
    --title "My Trajectories" --labels "Drone 1" "Drone 2" --save output.png
```

## Параметры

- `log_files` - путь(и) к файлу(ам) с логами (обязательный, можно указать несколько файлов)
- `--title` - заголовок графика (по умолчанию: автоматически генерируется)
- `--labels` - метки для каждого дрона (по умолчанию: автоматически генерируются из имени файла)
- `--save` - путь для сохранения графика (опционально, формат: PNG, PDF, SVG и т.д.)

## Особенности

### Для одного дрона:
- Автоматическое определение направления движения (стрелки на графике)
- Отметка начальной (зелёная) и конечной (красная) точек
- Информация о количестве точек и общем пройденном расстоянии
- Равные масштабы осей для корректного отображения траектории

### Для нескольких дронов:
- Разные цвета для каждой траектории (синий, красный, зелёный и т.д.)
- Легенда с метками для каждого дрона
- Отметки начальных и конечных точек для каждого дрона
- Стрелки направления движения (только для 1-2 дронов, чтобы не перегружать график)
- Информационная панель с данными о каждой траектории
- Равные масштабы осей для корректного сравнения траекторий

## Пример вывода

### Один дрон:
- Цветная линия - траектория движения
- Зелёная точка - начальная позиция
- Красная точка - конечная позиция
- Стрелки - направление движения
- Информационная панель с количеством точек и пройденным расстоянием

### Несколько дронов:
- Разноцветные линии - траектории каждого дрона
- Зелёные точки - начальные позиции
- Красные точки - конечные позиции
- Легенда с метками дронов
- Информационная панель с данными о каждой траектории
