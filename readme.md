В папке, где мы хотим создать проект, открываем консоль и запускаем развёртку виртуального окружения командой: python3 setup_env.py
Далее активируем виртуальное окружение командой:source drone_env/bin/activate
После чего можем запускать мир с нужным количеством дронов (данная строка запустит мир с тремя дронами): python3 run_sim.py --drones 3
