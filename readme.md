В папке, где мы хотим создать проект, открываем консоль и запускаем развёртку виртуального окружения командой: <br>
`python3 setup_env.py` <br>
Далее активируем виртуальное окружение командой: <br>
`source drone_env/bin/activate` <br>
После чего можем запускать мир с нужным количеством дронов (данная строка запустит мир с тремя дронами): <br>
`python3 run_sim.py --drones 3` <br>
